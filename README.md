Um projeto de banco de dados de clientes, para pequenhas empresas, ainda em desenvolvimento 
# 📊 Vision CRM Manager

Sistema profissional de gerenciamento de clientes desenvolvido em Python com CustomTkinter, SQLite e Matplotlib.

O projeto foi criado para fornecer uma interface moderna, intuitiva e eficiente para cadastro, consulta, análise e gerenciamento de clientes, incluindo dashboard com métricas em tempo real e exportação de relatórios.

---

## 🚀 Demonstração

### Principais funcionalidades

✅ Cadastro de clientes

✅ Pesquisa em tempo real

✅ Exclusão de clientes

✅ Dashboard profissional

✅ Indicadores estatísticos

✅ Clientes cadastrados por data

✅ Gráfico de evolução de clientes

✅ Relatórios gerenciais

✅ Exportação de PDF

✅ Tema Dark / Light Mode

✅ Interface moderna com CustomTkinter
